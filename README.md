# 🧠 Standard Format for Every Topic

Every important `.md` file should follow this structure:

```text
1. Introduction
2. Why do we need it?
3. Core concept
4. Syntax
5. Example
6. How it works internally
7. Memory/JVM behavior (when relevant)
8. Important properties
9. Advantages
10. Disadvantages / limitations
11. Comparison with related concepts
12. Common mistakes
13. Interview traps
14. Follow-up interview questions
15. Top interview questions
16. 30-second interview answer
17. Quick revision / cheat sheet
```

Not every topic needs every section.

Simple topics stay concise.

Important concepts go deep.
