# ☕ 07 — Control Statements

> Control statements determine the order in which statements execute in a Java program.

Normally, Java executes statements sequentially:

```text
Statement 1
    ↓
Statement 2
    ↓
Statement 3
```

Control statements allow us to change this flow.

---

# 1. Types of Control Statements

```text
Control Statements
│
├── Decision-Making
│   ├── if
│   ├── if-else
│   ├── else-if
│   └── switch
│
├── Looping
│   ├── for
│   ├── while
│   ├── do-while
│   └── enhanced for
│
└── Jump
    ├── break
    ├── continue
    └── return
```

---

# 2. `if`

Executes a block when a condition is `true`.

```java
int age = 22;

if (age >= 18) {
    System.out.println("Adult");
}
```

The condition must evaluate to `boolean`.

```java
if (true) {
    // valid
}
```

Unlike C/C++, Java does not allow:

```java
if (1) { } // compile-time error
```

---

# 3. `if-else`

```java
int age = 16;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}
```

Exactly one of the two branches executes.

---

# 4. `else-if`

Used when multiple conditions need to be checked.

```java
int marks = 75;

if (marks >= 90) {
    System.out.println("A");
} else if (marks >= 75) {
    System.out.println("B");
} else if (marks >= 60) {
    System.out.println("C");
} else {
    System.out.println("D");
}
```

Conditions are evaluated **top to bottom**.

Once a condition is true, the remaining `else-if` conditions are skipped.

---

# 5. Nested `if`

An `if` can exist inside another `if`.

```java
int age = 22;
boolean hasId = true;

if (age >= 18) {

    if (hasId) {
        System.out.println("Allowed");
    }
}
```

---

# 6. `switch`

`switch` selects one execution path based on a value.

```java
int day = 2;

switch (day) {

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    default:
        System.out.println("Invalid day");
}
```

Output:

```text
Tuesday
```

---

# 7. Why `break` Is Important in `switch`

Without `break`, execution can continue into subsequent cases.

Example:

```java
int x = 1;

switch (x) {

    case 1:
        System.out.println("One");

    case 2:
        System.out.println("Two");

    case 3:
        System.out.println("Three");
}
```

Output:

```text
One
Two
Three
```

This is called **fall-through**.

---

# 8. Switch Fall-Through

Fall-through means that after a matching case is found, execution continues into later cases until a `break`, the end of the switch, or another control transfer is reached.

Example:

```java
int month = 2;

switch (month) {

    case 1:
    case 2:
    case 3:
        System.out.println("Quarter 1");
        break;

    case 4:
    case 5:
    case 6:
        System.out.println("Quarter 2");
        break;
}
```

Multiple cases can therefore share the same block.

---

# 9. `default`

`default` executes when no case matches.

```java
int x = 10;

switch (x) {

    case 1:
        System.out.println("One");
        break;

    case 2:
        System.out.println("Two");
        break;

    default:
        System.out.println("Other");
}
```

Output:

```text
Other
```

`default` does not have to appear last.

Example:

```java
switch (x) {

    default:
        System.out.println("Default");

    case 1:
        System.out.println("One");
}
```

The actual execution still depends on matching/fall-through behavior.

For readability, `default` is normally placed at the end.

---

# 10. What Can Be Used in `switch`?

Traditional Java `switch` supports types such as:

```text
byte
short
char
int
enum
String
```

and their corresponding compatible constant expressions.

It does **not** directly support:

```text
float
double
boolean
long
```

as traditional switch selector types.

Example:

```java
double x = 2.5;

switch (x) { } // compile-time error
```

---

# 11. String in `switch`

Modern Java supports `String` in switch statements.

```java
String role = "admin";

switch (role) {

    case "admin":
        System.out.println("Admin");
        break;

    case "user":
        System.out.println("User");
        break;

    default:
        System.out.println("Unknown");
}
```

---

# 12. `switch` and `String` Comparison

A common interview question:

> Does `switch` use `==` for String comparison?

Conceptually, no.

Java's String switch implementation is based on the String's content/hash-based dispatch machinery generated by the compiler, followed by equality checks.

Therefore:

```java
String a = new String("Java");

switch (a) {

    case "Java":
        System.out.println("Matched");
        break;
}
```

can match `"Java"` based on String content.

---

# 13. Modern Switch Expression

Modern Java provides switch expressions.

Example:

```java
int day = 2;

String result = switch (day) {

    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Invalid";
};
```

Result:

```text
Tuesday
```

The arrow syntax avoids accidental fall-through.

---

# 14. `yield`

A switch expression can use `yield` when a case contains a block and needs to produce a value.

```java
int day = 2;

String result = switch (day) {

    case 1 -> "Monday";

    case 2 -> {
        String value = "Tuesday";
        yield value;
    }

    default -> "Unknown";
};
```

`yield` returns a value from a switch expression case.

---

# 15. `for` Loop

Used when repetition is controlled by a condition/counter.

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

Execution:

```text
Initialization
     ↓
Condition
     ↓
Body
     ↓
Update
     ↓
Condition
     ↓
...
```

---

# 16. `while` Loop

Checks the condition **before** executing the body.

```java
int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}
```

If the condition is initially false:

```java
while (false) {
    System.out.println("Hello");
}
```

the body executes **zero times**.

---

# 17. `do-while`

Executes the body first and checks the condition afterward.

```java
int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);
```

Therefore, the body executes **at least once**.

Example:

```java
int i = 10;

do {
    System.out.println("Hello");
} while (i < 5);
```

Output:

```text
Hello
```

---

# 18. `while` vs `do-while`

```text
while
↓
condition
↓
body
```

```text
do-while
↓
body
↓
condition
```

Therefore:

```text
while     → 0 or more times
do-while  → 1 or more times
```

---

# 19. Enhanced `for` Loop

Used mainly to iterate over arrays and `Iterable` collections.

```java
int[] numbers = {10, 20, 30};

for (int number : numbers) {
    System.out.println(number);
}
```

It simplifies iteration when you don't need the index.

---

# 20. Enhanced `for` and Index

You cannot directly obtain the index from the enhanced `for` syntax.

If you need an index:

```java
for (int i = 0; i < numbers.length; i++) {
    System.out.println(i + " " + numbers[i]);
}
```

Use the traditional loop.

---

# 21. `break`

`break` terminates the nearest enclosing loop or switch.

```java
for (int i = 1; i <= 10; i++) {

    if (i == 5) {
        break;
    }

    System.out.println(i);
}
```

Output:

```text
1
2
3
4
```

---

# 22. `continue`

`continue` skips the remaining body of the current iteration and proceeds to the next iteration.

```java
for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        continue;
    }

    System.out.println(i);
}
```

Output:

```text
1
2
4
5
```

---

# 23. `break` vs `continue`

```text
break
↓
Exit the loop

continue
↓
Skip current iteration
↓
Continue loop
```

---

# 24. `continue` in a `while` Loop

Be careful with updates.

This can become an infinite loop:

```java
int i = 0;

while (i < 5) {

    if (i == 2) {
        continue;
    }

    i++;
}
```

When `i` becomes `2`:

```text
continue
↓
i++ is skipped
↓
i remains 2
↓
condition remains true
↓
continue again
```

Therefore, the loop never progresses.

---

# 25. `return`

`return` exits the current method.

```java
static void test() {

    System.out.println("Start");

    return;

    // code here would be unreachable
}
```

For a value-returning method:

```java
static int add() {
    return 10 + 20;
}
```

`return` can therefore:

```text
1. Exit a method
2. Return a value
```

---

# 26. Labeled Statements

Java supports labels with loops.

```java
outer:
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {

        if (i == 2 && j == 2) {
            break outer;
        }

        System.out.println(i + " " + j);
    }
}
```

`break outer` exits the loop associated with the `outer` label.

---

# 27. Labeled `continue`

```java
outer:
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {

        if (j == 2) {
            continue outer;
        }

        System.out.println(i + " " + j);
    }
}
```

This skips to the next iteration of the **outer** loop.

---

# 28. Scope of Loop Variables

A variable declared in a `for` loop has scope limited to that loop.

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// System.out.println(i); // error
```

`i` no longer exists outside the loop.

---

# 29. Infinite Loops

A loop whose condition never becomes false can execute indefinitely.

```java
while (true) {
    System.out.println("Running");
}
```

Another example:

```java
for (;;) {
    System.out.println("Infinite");
}
```

`for (;;)` is a valid infinite loop.

---

# 30. Empty Loop

A loop body can technically be empty.

```java
for (int i = 0; i < 10; i++);
```

The semicolon is the loop body.

Therefore:

```java
for (int i = 0; i < 10; i++);
System.out.println("Hello");
```

prints:

```text
Hello
```

only once.

This is a common output-based interview trap.

---

# 31. Nested Loops

A loop can contain another loop.

```java
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {

        System.out.println(i + " " + j);
    }
}
```

If each loop executes `n` times:

```text
Outer loop → n
Inner loop → n
Total      → n²
```

So the time complexity is generally:

```text
O(n²)
```

for equal-sized independent nested loops.

---

# 32. `break` in Nested Loops

An unlabeled `break` only exits the **nearest** loop.

```java
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {

        if (j == 2) {
            break;
        }

        System.out.println(i + " " + j);
    }
}
```

The inner loop stops, but the outer loop continues.

---

# 33. `continue` in Nested Loops

An unlabeled `continue` applies to the nearest enclosing loop.

```java
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {

        if (j == 2) {
            continue;
        }

        System.out.println(i + " " + j);
    }
}
```

Only the current inner-loop iteration is skipped.

# 34. Common Interview Traps

## Trap 1 — `if` accepts integers

```java
if (1) {
    System.out.println("Hello");
}
```

❌ Compile-time error.

Java requires:

```java
boolean
```

---

## Trap 2 — `do-while` executes zero times

Wrong.

```java
do {
    System.out.println("Hello");
} while (false);
```

Output:

```text
Hello
```

It executes once.

---

## Trap 3 — Missing `break`

```java
int x = 2;

switch (x) {

    case 1:
        System.out.println("A");

    case 2:
        System.out.println("B");

    case 3:
        System.out.println("C");
}
```

Output:

```text
B
C
```

Because of fall-through.

---

## Trap 4 — `break` exits all nested loops

Wrong.

```java
break;
```

only exits the nearest enclosing loop/switch unless a label is specified.

---

## Trap 5 — `continue` exits the loop

Wrong.

```java
continue;
```

only skips the current iteration.

---

## Trap 6 — Infinite `while` loop

```java
int i = 0;

while (i < 5) {
    System.out.println(i);
}
```

`i` never changes, so the condition remains true.

---

## Trap 7 — Semicolon after loop

```java
for (int i = 0; i < 5; i++);
{
    System.out.println("Hello");
}
```

The loop has an empty body.

The block after it is separate and executes once.

# 36. Interview Questions

## Basic Questions

### Q1. What are control statements?

Statements that control the execution flow of a program.

---

### Q2. What are the major types?

```text
Decision
Looping
Jump
```

---

### Q3. Difference between `while` and `do-while`?

`while` checks the condition before execution.

`do-while` checks it after execution.

Therefore:

```text
while     → 0 or more
do-while  → 1 or more
```

---

### Q4. What does `break` do?

Terminates the nearest enclosing loop or switch.

---

### Q5. What does `continue` do?

Skips the current iteration and proceeds to the next iteration.

---

## Conceptual Questions

### Q6. Why does Java not allow `if(1)`?

Java requires the condition of `if` to be a boolean expression.

---

### Q7. What is fall-through in switch?

When execution continues into subsequent cases after a matching case because there is no control transfer such as `break`.

---

### Q8. Can `default` appear before `case`?

Yes.

The compiler allows it, although placing `default` last is conventional for readability.

---

### Q9. Can switch use String?

Yes.

Java supports `String` in switch.

---

### Q10. Can switch use `float` or `double`?

No, traditional Java switch does not support floating-point selector types.

---

### Q11. Can switch use `long`?

No.

---

### Q12. Can switch use `enum`?

Yes.

---

### Q13. Can a switch have duplicate case values?

No.

Duplicate case labels result in a compile-time error.

---

### Q14. Can two cases share the same body?

Yes.

```java
case 1:
case 2:
case 3:
    System.out.println("Group 1");
    break;
```

---

### Q15. Can a loop have no body?

Yes.

```java
while (condition);
```

The semicolon becomes the empty statement/body.

---

# 37. Advanced / Tricky Questions

### Q16. What happens if `continue` is used in a `while` loop before the update statement?

The update may be skipped, potentially causing an infinite loop.

---

### Q17. What does an unlabeled `break` do in nested loops?

It exits only the nearest enclosing loop.

---

### Q18. How can you exit an outer loop from an inner loop?

Use a labeled `break`.

```java
outer:
for (...) {
    for (...) {
        break outer;
    }
}
```

---

### Q19. How can you skip directly to the next iteration of an outer loop?

Use labeled `continue`.

```java
outer:
for (...) {
    for (...) {
        continue outer;
    }
}
```

---

### Q20. Does `break` work with `if`?

`break` can be used inside a loop or switch. It cannot be used simply inside an ordinary standalone `if` block.

---

### Q21. What is the difference between `return` and `break`?

```text
break
→ exits loop/switch

return
→ exits method
```

---

### Q22. What happens if no case matches and there is no default?

Nothing inside the switch executes.

Execution continues after the switch.

---

### Q23. Is `default` mandatory in switch?

No.

---

### Q24. Can `case` values be variables?

Case labels generally need compile-time constant expressions (with the rules applicable to the switch form).

A normal runtime variable cannot simply be used as a case label.

---

### Q25. Why are enhanced `for` loops useful?

They simplify iteration when you need elements rather than indexes.

---

Execution can continue into the next cases.

If the code responsible for updating the loop-control variable occurs after `continue`, it may never execute.

A switch statement primarily controls execution flow.

A switch expression produces a value and can use arrow labels and `yield` where required.

# 🎤 30-Second Interview Answer

> Java control statements control the flow of program execution. They are mainly divided into decision-making, looping, and jump statements. Decision-making includes `if`, `if-else`, and `switch`; loops include `for`, `while`, `do-while`, and enhanced `for`; and jump statements include `break`, `continue`, and `return`. Important interview concepts include switch fall-through, the difference between `while` and `do-while`, short-circuit behavior in loop conditions, and how labeled `break` and `continue` work with nested loops.
